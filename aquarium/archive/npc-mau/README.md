# NPC mẫu (không còn trong game)

Ba tệp của NPC mẫu đứng ngoài bể (bảng thử cử chỉ, biểu cảm khuôn mặt). Game đã bỏ NPC mẫu; `index.html` không nạp các
tệp này. Để ở đây để dùng lại khi cần (ví dụ trang thử nhân vật), không sửa theo code mới.

- `model3d.js`: dựng một NPC mẫu lớn, xoay, đổi trang phục theo thời.
- `face3d.js`: biểu cảm khuôn mặt (mắt, miệng, lông mày) theo cử chỉ.
- `model-ui.js`: bảng chọn cử chỉ, biểu cảm cho NPC mẫu.
