## Bể Kính: cài bằng một lệnh

Tải toàn bộ mã nguồn về máy, tạo phần mềm "Bể Kính" có biểu tượng và mở game (chơi không cần mạng):

- Windows (PowerShell):

  ```powershell
  irm https://raw.githubusercontent.com/npt275-ops/cloud-session/claude/eloquent-faraday-raquyc/install.ps1 | iex
  ```

- macOS, Linux (Terminal):

  ```bash
  curl -fsSL https://raw.githubusercontent.com/npt275-ops/cloud-session/claude/eloquent-faraday-raquyc/install.sh | bash
  ```

Điện thoại: mở https://npt275-ops.github.io/cloud-session/ (cần bật GitHub Pages cho thư mục `docs/` một lần) rồi thêm vào
màn hình chính.
